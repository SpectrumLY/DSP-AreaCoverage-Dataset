# DSP-AreaCoverage-Dataset
The files provided include the hexagonally gridded map with the adjacency list for the grids, as well as the revenue for each grid at each time step.  

./test_case : The test case is adapted from the Emission Control Area in the coastal waters near the Yangtze River Delta region of China. Each revenue value is randomly generated.

./real_case_based_on_AIS : The real case is the maritime area near Galveston Island, located within the Emission Control Area of the Gulf of Mexico in North America. The revenue is derived from the AIS data.
